Reproduce the benchmark in a few commands

Linux + NVIDIA GPU

1Get the code

Downloads the benchmark scripts.

git clone https://github.com/Sanmay-Das/Benchmarking-GeoFMs-for-Agriculture-Applications
cd Benchmarking-GeoFMs-for-Agriculture-Applications

2Set up

Gets Python 3.9 and builds one environment per model (about 15 minutes).

curl -LsSf https://astral.sh/uv/install.sh | sh
~/.local/bin/uv python install 3.9
GFM_PYTHON=$(~/.local/bin/uv python find 3.9) ./setup.sh

3Get the data and weights

Downloads only what one experiment needs from Hugging Face.

venvs/prithvi/bin/python scripts/fetch.py --task cd --model prithvi --state minnesota

4Run

Runs the model and prints the scores.

./reproduce.sh --task cd --model prithvi --state minnesota
